# 🌍 Emissions Analytics Dashboard

> Interactive Data Analytics Dashboard built using Databricks SQL to analyze emissions trends across the United States through geospatial and statistical visualizations.

## 📌 Project Overview

The Emissions Analytics Dashboard is an interactive dashboard developed in Databricks to explore and analyze emissions data across different US counties and states.

The dashboard provides:
- 📍 Geospatial emissions mapping
- 📊 State-wise emissions contribution
- 📈 Population vs Emissions analysis
- 🏙 County-level emission comparison
- 📉 Interactive visual insights

This project demonstrates practical skills in:
- Data Analytics
- SQL Querying
- Dashboard Development
- Data Visualization
- Business Intelligence

# 📊 Dashboard Insights

🔹 Geographic Emissions Distribution
Visualizes emissions across the US using geospatial point mapping.

🔹 Population vs Emissions
Analyzes correlation between population density and emissions per person.

🔹 State Contribution Analysis
Identifies states contributing the highest percentage of emissions.

🔹 County-Level Comparison
Highlights counties with maximum CO₂ emissions.
